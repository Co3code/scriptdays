Day 11: DOM Intro

LESSON: Document Object Model

  • document.getElementById('id') → select element by ID
  • document.querySelector('.class') → first element matching selector
  • document.querySelectorAll('.class') → all matching elements (NodeList)
  • element.textContent → get/set text
  • element.style.property → get/set CSS styles
  • element.classList.add/remove/toggle → manage CSS classes
  • element.innerHTML → get/set HTML content
